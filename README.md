# grok-workspace

نظام مساحة عمل Grok لبناء التطبيقات (App Builder Workspace)

هذا المستودع يحتوي على نظام مساحة عمل Grok الكامل، بما في ذلك المهارات (skills) والمراجع والسكربتات لبناء تطبيقات ويب وPWA.

## الوصف
منصة Lingo لتعلم الإنجليزية تعمل محليًا — صنع بواسطة لقمان.

## كيفية الاستخدام
1. استنسخ المستودع:
   ```bash
   git clone https://github.com/mesterlogman-alt/grok-workspace.git
   cd grok-workspace
   ```
2. ثبت الاعتمادات:
   ```bash
   npm install
   ```
3. شغل التطبيق:
   ```bash
   npm run dev
   ```

## ملاحظات
- المستودع عام (Public).
- يحتوي على ملفات skills في مجلد `.grok/skills`.
- المشروع مبني على Vite + React + TanStack Router.

تم إنشاء المستودع ورفعه بواسطة Grok.
